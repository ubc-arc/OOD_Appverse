## [0.1.0] - 2025-03-18
### Added

* Initial release of IGV Open OnDemand app.
* Apptainer container bundling IGV 2.17.0 with Java 17 built on Ubuntu 22.04.
* VNC-based desktop session using Xfce window manager.
* Form options for allocation code, number of cores, and session duration.
* Support for custom genome server via a local genomes.tsv file.
* Support for IGV interactive GUI via X11/VNC within the container.
