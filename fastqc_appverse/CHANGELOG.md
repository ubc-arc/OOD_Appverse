## [0.1.0] - 2026-03-25
### Added
- Initial release of FastQC Open OnDemand app.
- Apptainer container (fastqc_0.12.1.sif) bundling FastQC 0.12.1 on Ubuntu 22.04.
- VNC-based desktop session using Xfce window manager.
- Form options for allocation code, number of cores, and session duration.
- Support for FastQC interactive GUI via X11/VNC within the container.
